HOSPITAL MANAGEMENT SYSTEM for CENG201 HOMEWORK (27 December 2025)

OVERVIEW:

This project simulates a simple hospital management system. It allows:
• Adding patients with ID, name, age, and severity. 
• Handling treatment requests, including priority treatments.
• Removing patients and printing the patient list.
• Sorting patients by severity.

FILES: 
• Patient.java → Stores patient information. 
• PatientList.java → Manages the list of patients and related operations. 
• TreatmentRequest.java → Represents a treatment request for a patient. 
• HospitalSystem.java → Core system that handles patients and treatments. 
• Task4Test.java → Test class for Task 4 functionalities (adding patients, processing treatments, printing, and sorting).

HOW TO RUN? : 
1. Compile all .java files. 
2. Run Task4Test to see example usage: 
• Patients are added. 
• Treatments are processed, respecting priority. 
• Current system state is printed. 
• Remaining patients are sorted by severity.

FEATURES IMPLEMENTED: 
• Add and remove patients. 
• Print current patient list. 
• Process treatment requests (priority and normal). 
• Sort patients by severity.
